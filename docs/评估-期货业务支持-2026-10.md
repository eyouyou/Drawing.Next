目标：判断本框架能不能撑起期货终端的全部图表(参照 FuturesPC 现有功能与 hevo.drawing 已迁的业务层),撑不住的地方在框架里怎么调整。下一步再用 Newhsetup 的全部图表(含图上交易)冲击框架。

- **初评基准**:WPFDrawing.Next `main` d2f4bd4;业务层 hevo.drawing `master` 9ac9a9c。
- **本次更新**:WPFDrawing.Next `main` 766e4ff;hevo.drawing `master` df26f32。已完成的条目标「已完成」并附提交号。
- **方法**:静态阅读加逐项对照代码，每条都带出处;已完成的条目以提交里的测试为证。
- **前提**:按"框架改动开关规则",嵌进现有模块的新行为一律加配置、默认保持原行为;独立模块靠装不装 Feature 控制。
- **写法**:每条先写用户能看到的现象，再写原因、改法。

出处缩写:`C/` = `Hevo.Charting.Core/`,`W/` = `Hevo.Charting/`,`HD/` = hevo.drawing 仓库。

## 数据与视口

### 已完成

**往左翻历史时画面跳一页;停在最早历史上看时，每来一根新 bar 画面被推走一根。**
- 原因：视口只看到"逻辑长度变了",靠长度差猜是前插还是追加，用户拖离左侧缓冲区后就会猜错(`Hevo.Charting.Tests/ViewportLengthGuessTests.cs` 钉住了两个错猜时机)。
- 改法：数据源知道每根是谁，就随快照发布 `DataExtent(epoch, keys, olderExhausted)`;视口按"最左那根的键"找回位置，贴右且末尾来了新键时才跟随最新，裁决后把锚点键写进 `Viewport.AnchorKey`。不发 `DataExtent` 的数据源行为不变。复权 / 换月这种键没变、值全变的整段替换，换一个 `epoch`。
- 提交:f0e69e5(`DataExtent` 随快照发布)、a2f0357(视口按键锚定)。用法见 [00 号文档 §12.1](../Hevo.Charting/00.架构协议与开发规范.md),范例 `Hevo.Charting.Tests/DocSamples/Paging/`(819fe87)。

**跳到某个日期(包括还没加载的日期)。**
- 改法:`ViewportManagerFeature.ScrollToKey(key)`:目标居中;目标还没加载时先停最左、锚点留在目标上，分页模块按锚点一次补齐空档后再居中。切合约 / 切周期后数据还没到就调(恢复位置)也生效，首个带键的帧到达时落位。
- 提交:a2f0357、d2625bf(数据到达前调用)。

**翻页由谁拉、拉多少、何时到底。**
- 原因：框架原来的翻页回调按下标问"还要几根",到底判据、页大小、失败重试都压在业务回调里，每个屏幕写一遍且容易把失败当成到底。
- 改法：框架只问 `DataPagingFeature.OnRequireBefore(key, count)` ——"键 key 之前至少还要 count 根",在黑板锁内被调、立即返回;拉不拉、一页多少、补空档都由数据源定，左墙从 `OlderExhausted` 换算。翻页的细节(首屏、按键往前翻、页大小自适应、到底判据、失败冷却、切合约丢旧回包)放在 hevo.drawing Foundation 的 `PagedSourceBase`,适配层只实现"拉最新 N 根"和"拉某键之前 N 根"。
- 提交：框架 5e4f90f、dd91382(`EnableStandardPointer` 可传 `onRequireBefore`)、d0fbf32(蓝图端口 `VP_Extent`);业务层 HD 9624dca,评估见 HD `docs/迁移/评估-分页数据源.md`。

**切合约 / 切周期后回到首屏。**
- 改法：切合约仍走 `SwitchContext` 的空帧(长度归零 → 视口回首屏);`ReactiveDataSource.OnContextSwitching` 钩子让分页数据源在两个切换入口都先清空、发空帧，副图不会残留旧合约数据。
- 提交:f0e69e5。

**切合约、前插历史后增量指标算错(末根重复计入、前插后没重算)。**
- 改法:`IncrementalComputeFeature.ExtentPort = Chart.Viewport.Extent` 时，纪元换了或前插 / 补洞就清状态重算，追加和改末根续算。默认不配 = 原行为。
- 提交:66dc301。

**多源分时对比(双分时屏、指数风向标)接不了 Foundation 的帧式数据源。**
- 改法:`TimeAxisCoordinator` 加一个 `AddSource` 重载，帧式数据源传"点数 / 第 i 个时间 / 第 i 个值"即可参与时间对齐;蓝图管线策略登记表在精确类型没登记时沿基类链回退。
- 提交:766e4ff(业务层 HD f215193、df26f32)。
