## 2. 指针路由器(strange-archimedes)

**做了什么**
- `PointerRouterFeature`:由 `ChartReactiveSchema` 强制挂上(同 `ViewportPortsFeature`),每个 schema 一份、拔不掉。**没有任何区域时什么都不做**:不标 Handled、不抓鼠标、不设光标、不写手势端口。
- 路由器成为 ChartCell 唯一的输入入口;WPF 只留在 `WpfPointerAdapter` 里。`ChartInteractionFeature` 不再订 WPF 事件、不再引用 `System.Windows.Input/Media`,改为兜底处理器(`IPointerBackground`):没被区域认领的输入由适配器的冒泡订阅转给它,时序同原冒泡订阅。
- Feature 在 `OnProject` 里经 `ctx.Pointer().Publish(region)` 发布区域;路由器按优先级 → 图层 → 距离裁决;一次手势的全过程写进 `PointerPorts.GesturePort`,业务用 `.WatchPointer(owner, handler)` 订阅。
- `ElementPlotFeatureBase` 改发布框架内部的现算命中区域,悬停 / 离开 / 双击走手势端口。
- 内置两个新 Feature:可拖水平线、测量。

**新公开 API**(命名空间 `Hevo.Charting.Interaction` 为主)
- 类型:`PointerRegion`(record:`Id`/`Part`/`Shape`/`Accepts`/`Cursor`/`DragCursor`/`Tolerance`=4/`Priority`=Object)、`PointerShape`、`PointerAccepts`、`PointerPriority`(Object=100 / Handle=200 / Modal=1000)、`PointerPhase`、`PointerCancelReason`、`PointerButton`、`PointerModifiers`、`PointerCursor`、`PointerGesture`、`PointerPorts`、`PointerRouterFeature`。
- 扩展:`FeatureContext.Pointer()` → `PointerPublisher.Publish/Clear`;`FeatureContext.UseProjection(valueRangePort)` → `ChartProjection`(屏幕 ↔ 逻辑坐标);`IRenderFlow.WatchPointer(owner, PointerGestureHandler)`。
- `ChartFeature.Pointer`(`PointerPorts`);手势回调里 `CancelGesture()` 取消当前手势。
- `InteractionBuilder.AddDraggableLine(pricePort, valueRangePort, DraggableLineOptions?)` / `AddMeasure(valueRangePort, MeasureOptions?)`;对应 `DraggableLineFeature` / `MeasureFeature`。
- `BoxZoomOptions` 移到单独文件,新增 `Activation`(`PointerModifiers`)。

**新选项与默认值**
| 选项 | 默认 | 说明 |
|---|---|---|
| `InteractionOptions.DragThreshold` | 4.0 DIP | 指针区域的拖动阈值(唯一来源) |
| `ChartInteractionMode.KeyboardZoom` | 不在 `All` / `Default` 里 | ↑ 放大 / ↓ 缩小,要显式加上 |
| `BoxZoomOptions.Activation` | `Shift` | 旧 `ActivationModifier` 标 `[Obsolete]`,照常生效并换算到 `Activation` |
| `ElementPlot…DoubleClickClaimsPress` | false | false = 跟原来一样,元素双击和图表双击复原都触发 |
| `PointerRouterFeature.FlushPendingFrameOnPress`(静态) | true | 按下时先同步跑掉排队的帧再命中;只在发布过区域的图表上生效 |
| `DraggableLineOptions` | `LiveWrite`=true、`Tolerance`=4、`LabelFormat`="F2"、`ReadOnly`=false | 新 Feature |
| `MeasureOptions.Modifier` | `Control` | 新 Feature |

## 3. 静默层诊断 / UpdateData / 代理唤醒(g6-layer-redraw)

- **Debug 静默层诊断**(仅 Debug 编译):图层挂上 120 帧都没录出任何指令,输出窗口报一次原因与改法(没喂过本层数据 / 读到的 Trait 在两个作用域都是 null)。只写日志,不抛、不标脏、不改渲染状态;隐藏的帧不计数。深度睡眠本身不变(有意为之,没有强制重画入口)。
- **修 bug:`LayerProxyExtensions.UpdateData` / `SharedProxyExtensions.UpdateData`** 原来把委托本身当 Trait 发出去,图层永远读不到新值;改为"读旧值 → 调 modifier → 发新值"。本仓库与 hevo.drawing 都没有调用方。
- **修 bug:`ChartCell.AddUnmanagedLayer` 返回的代理喂数据会唤醒图层**(新 `LayerFeed`,任何线程都可以喂,下一帧唤醒并录制)。原来经代理喂的数据不唤醒图层、图层永远不画。`Feature.AttachLayer` 改走 internal `AttachFeatureLayer`,行为与原来一致(直写本层 live 袋、不唤醒)。
- 文档:术语表补"共享作用域 / 本层作用域"、"深度睡眠";00 号文档 §16.1。

## 4. 填充指令(g7-fill-drawing)

- 新增 `DrawOp.DrawPolygon`、`DrawOp.DrawBand`(追加在枚举末尾,已有指令值不变)。
- `IDrawingSink.DrawPolygon(brush, pen, List<HevoPoint>)`:闭合多边形,填充 + 可选描边,非零环绕。
- `IDrawingSink.DrawBand(brush, pen, HevoBand, crossedBrush = null)`:两条折线之间的带状填充;`HevoBand.Add(x, upperY, lowerY)`、`AddGap()`(NaN 断带)、跨帧复用 0-GC;给 `crossedBrush` 时按上下穿越分两色,穿越点线性插值。

- 文档:06 号文档 §4.7;DocSample `Fill/RangeShadeLayer`。

## 5. 联动 pane 分隔条(pane-splitter)

- `LinkedChartDashboard.IsPaneResizeEnabled`,**默认 false**:只有 pane 行、无分隔条行、行无 MinHeight、Children 只有 cell,与改动前逐项一致;运行期删 / 加 pane 同旧。
- 打开后:相邻 pane 之间放 `PaneSplitter`(dashboard 自己的 WPF 元素,不走图表交互管线),悬停 SizeNS,拖动只在两侧 pane 之间重分,双击复位;高度按星号比例保存,窗口缩放按比例重排。
